01 About

Building with code,
reasoning with data.

I'm Pari Gull — a web developer and data analyst. I build interfaces that feel effortless, and I work with data until it tells a clear, usable story.

On the web side, I build responsive, accessible front-ends with semantic HTML, modern CSS and JavaScript, and I use Python for the logic behind them — from interactive calculators to multi-page sites that stay fast and readable.

On the data side, I work with SQL, Python and Excel to clean, model and visualise real datasets: descriptive statistics, regression, forecasting and dashboards that support actual decisions rather than decoration.

A mathematical way of thinking shapes how I work — break the problem down, model it, test it, then ship it. I care about clean code, careful detail and answers that hold up under scrutiny.

  • Build

    Responsive interfaces and interactive tools that work on every screen.

  • Analyse

    SQL, Python and Excel workflows that turn raw data into insight.

  • Solve

    Mathematical modelling, algorithms and structured debugging.

Currently focused on

  • Supervised machine learning — regression, classification and model evaluation
  • Full-stack analytics projects: data modelling to dashboard
  • Writing clearer, faster, more accessible front-end code
